# Security Policy

## Supported Versions

Currently, only the latest release of **Quantum Forge** receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Quantum Forge, please DO NOT open a public issue. Instead, please report it privately.

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.

We will review the report and aim to provide a response within 48 hours. Once the issue is resolved, we will publish a security advisory and notify the reporter.
